# MLPerf input data

This directory contains the two MLPerf Inference v6.1 Closed-division exports
used by the GraphSAGE experiment:

| Suite | File | Rows | Systems | SHA-256 |
| --- | --- | ---: | ---: | --- |
| Datacenter | `raw/Table - Inference_Full Data_data.csv` | 457 | 87 | `8b5ccfe2143281e2ae266de03fbec8e57e69b86aeaa5938de0e578fef47d2d1f` |
| Edge | `raw/Table - Inference_edge.csv` | 19 | 9 | `e814a07701936a5453909bd94f999681269734e487a90bd38b86f7808bac9c80` |

The files are UTF-16, tab-separated exports. `mlperf_long.csv` is generated by
`ai_benchmark.prepare_data` and contains 476 normalized measurements from 96
independent system identifiers.

Source: [MLCommons Inference Results v6.1](https://github.com/mlcommons/inference_results_v6.1).
The original exports are public benchmark metadata and measurements. They are
not accuracy-compliance records and do not contain hardware profiler counters.
